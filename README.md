# Checklist vehicular 360° · Los Azules

Versión web de prueba para Safari en iPhone y otros navegadores compatibles.

- Hasta 20 fotos, 12 controles de seguridad, mapa de daños, firmas y PDF.
- Guardado local en el dispositivo. No incluye un servidor de registros ni envíos automáticos a SSGG.
- Abrir por HTTPS, agregar a la pantalla de inicio y esperar que se complete la descarga antes de probar en modo avión.
- Verificar fotos, PDF, firmas e historial en el dispositivo antes de usar operativamente.
- La fecha y hora se toman del teléfono. Conservar PDF y copias de respaldo.

El contenido de este repositorio es público. Los registros completados no se suben a GitHub.
